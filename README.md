# QA Exercise — Manual Matching (20 min)

## Context

A higher education platform connects students (mentees) with alumni (mentors) through a mentoring
program. Program administrators can manually create matches between participants.

## Feature: Manual Matching

Program administrators can create a match between a mentee and a mentor from the program dashboard.
When a match is created:

- The match appears in both participants' dashboards
- Both participants receive an email notification
- The match is reflected in the program's reporting data

## Additional context

- Mentors set their own capacity — the maximum number of mentees they are willing to mentor at once
- A mentee can only have one active mentor at a time
- Both participants must be active and enrolled in the same program to be matched

## Your tasks

1. Write test cases for this feature — include happy path and edge cases
2. Rank your test cases by risk/priority
3. For each test case, indicate whether it should be **manual**, **automated**, or **either** — and
   briefly explain why
